    這些套件站在哪一層

    套件不會憑空畫圖，每一個都是蓋在瀏覽器原生 API 上的一層。這張圖由上往下讀：套件 → 瀏覽器 API → 硬體。

    • 看連線游標移到套件上，會畫線連到它用的 API；移到 API 上，會亮出所有用到它的套件。
    • 深色 = 有示範深色的套件在上方有即時示範，點一下就跳過去；淺色的只是列出來參考。
    1套件與作法寫程式時引用的工具；最右一欄是不靠套件、直接寫的作法
    所有動畫跟著同一個節拍 requestAnimationFrame：螢幕每刷新一次（通常一秒 60 次），就一起畫下一格
    2瀏覽器原生 API瀏覽器內建的畫圖、發聲能力，上面每個套件都是在呼叫它們
    3硬體最後真正算圖、發出聲音的地方
    CPU 算版面、畫圖　→　GPU 疊圖層、上色GPU 大量運算音效輸出
