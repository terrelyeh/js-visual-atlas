# JS 視覺生態圖譜

12 個 JavaScript 視覺套件與瀏覽器原生 API、60 種即時效果。這一頁沒有任何圖片、影片或音檔，所有畫面和聲音都是瀏覽器裡的 JavaScript 即時算出來的。

公開網址：https://js-visual-atlas.vercel.app

## 頁面內容

- **12 個示範，每個 5 個分頁**：分頁之間切換時，右邊資訊卡會跟著換成這一頁的內容。
- **這一頁怎麼玩**：60 個分頁各有一句自己的玩法，寫的是這一頁實際能做的操作，顯示在右邊資訊卡；畫面左下角另有簡短的操作提示。
- **跟 AI 這樣說**：每個分頁附一段範例提示詞，教你怎麼跟 AI 描述才能做出這個效果。
  - **照五個步驟排**：先寫用哪個套件，再分行寫「畫面：」「怎麼動：」「互動：」「限制：」，跟上方的五個步驟一一對應。複製出來的文字也是分行的。
  - **【】標出可替換的主題**：括號裡是這個示範的主題（例如【黃昏山景】、【營收、使用者、平均停留秒數】），換成自己的內容即可；括號外是做出效果的寫法，照抄就好。少數幾段整段都是效果本身（例如類比時鐘），就沒有括號。
  - **關鍵詞**：只放跟效果有關的詞（技術名稱、做法），不放主題詞。
- **分頁網址**：每個分頁都有自己的網址，例如 `#gsap/3` 是 GSAP 的第三個分頁（SplitText），可以直接把某個效果傳給別人。只寫 `#gsap` 會開第一頁。
- **影片版提示詞**：範例提示詞上方可以切換「網頁版／影片版」。影片版會拿掉「互動：」那段，並在限制裡補上錄影片需要的條件（一條時間軸控制、不靠點擊、固定隨機種子、畫面尺寸和總長）；聲音類的示範另外說明聲音要分開錄。選擇會記在瀏覽器裡。
- **用到的瀏覽器 API**：資訊卡和示範卡片只列這個示範實際用到的 API；上方圖譜列的是套件本身支援的 API，所以兩邊可能不同（例如 Three.js 在圖譜連到 WebGPU，但示範只用 WebGL）。

## 修改內容時

- 分頁定義在 `MOUNT.<id> = tabbed(...)`，每個分頁是 `{ name, mount, play, code, ask }`；`play` 就是「這一頁怎麼玩」。
- 提示詞在 `ASK`（各示範的第一個分頁）和 `CANVAS_ASK`、`D3_ASK` 這類 `*_ASK` 物件裡，格式是 `{ terms, prompt }`。新增或修改時，請照五個步驟的順序寫，並保留「畫面：」「怎麼動：」「互動：」「限制：」四個小標（畫面上會自動標色、換行），可替換的主題用【】括起來。
- 示範實際用到的 API 寫在 `DEMOS` 的 `base`；圖譜用的是 `CATS`，兩者分開維護。

## 檔案

- `index.html`：整個網站，單一檔案。它是頁面片段（沒有 `<!doctype>`），因為同一份檔案也發布成 claude.ai Artifact，Artifact 會自動補上外層結構。
- `build.sh`：把 `index.html` 包成完整的 HTML 頁面，輸出到 `dist/`。
- `vercel.json`：告訴 Vercel 用 `build.sh` 打包、發布 `dist/`。

## 部署

推到 `main` 就會自動部署到正式網址。推到其他分支會產生預覽網址（需要登入 Vercel 才看得到）。

本機預覽：

```sh
sh build.sh && open dist/index.html
```
